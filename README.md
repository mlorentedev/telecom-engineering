# Telecom Engineering

Coursework projects from the **Grado en Ingenieria en Tecnologias de Telecomunicacion (GITT)** degree program.

## Projects

| Directory | Project | Language | Description |
|-----------|---------|----------|-------------|
| `algorithms/dijkstra` | Dijkstra's Algorithm | C | Shortest path algorithm implementation for graph traversal |
| `networking/dns-client` | DNS Client | C | TCP file transfer and UDP query modes for DNS communication |
| `microcontrollers/pic16f84a-fsm` | Athletic Training System | ASM | PIC16F84A finite state machine with LCD — 100m sprint reaction/race timer |
| `signal-processing/dsk6713-audio-effects` | DSP Audio Effects | C | Chorus and Tremolo effects for the TI DSK6713 DSP platform |

## Structure

```
telecom-engineering/
├── algorithms/

    └── dsk6713-audio-effects/  # Audio FX (C)
```
